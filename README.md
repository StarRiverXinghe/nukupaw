# nukupaw

> 本地优先的陪伴服务框架 —— **早期开发中，尚未发布**。

这个包目前只是**占位**，不含任何实现。安装它只会得到一个说明现状的命令：

```
nukupaw
```

等框架有了可用的第一个版本，这里会被真正的实现替换。

## 设计取向

- **本地优先** —— 模型、数据、状态都在你自己的机器上，不依赖任何托管服务。
- **上下文可控** —— 每一轮发给模型的内容都有明确预算，超了按规则裁剪。
- **状态是演化出来的** —— 角色有连续的内在状态，随时间自然变化。
- **记忆分层** —— 近期原文、长期索引、提炼后的条目分开存放。
- **投递像人说话** —— 一条回复按停顿切成几段发出来。
